# GHP冷媒配管サイズアップ検証手順

## 目的

GHPの長配管条件を、施工総延長・最長経路長・実長・相当長と混同せず、メーカー・シリーズ・運転方式・対象区間ごとに確認する。根拠資料が一致しない条件は自動選定に実装しない。

## 現時点で確認した公式資料

1. **ヤンマー GHP総合カタログ（2020年11月版、冷媒配管関係）**
   - URL: https://www.yanmar.com/media/jp/2020/ebook/ghp-dh_202011/HTML/index276.html
   - 該当ページには、ロング配管時（相当長90m以上）にガス管サイズを1サイズアップし、冷房時の能力低下を抑えることが可能との記載がある。
   - 適用対象のシリーズ・配管区間・管径表を同じ資料内で確定してから実装すること。2020年版の記載だけで現行全機種へ一般化しない。

2. **ダイキン GHPエグゼアII 冷暖フリー施工概要（2025年1月発行）**
   - URL: https://ec.daikinaircon.com/ecatalog/CP21067FXX/images/CP21067FXX221.pdf
   - 配管区分（室外機～分岐キット、分岐キット間、BSユニット関連など）ごとに管径表が分かれている。また、ロング配管時（相当長90m以上）のガス管1サイズアップについて注記がある。
   - 対象区間と表の機種条件を照合し、冷暖フリーと冷暖切換を同じルールにまとめない。

3. **Panasonic 空調設備設計資料／設備設計ガイド**
   - URL: https://panasonic.co.jp/hvac-cc/biz/manual/
   - ビル用システムマルチとGHPの資料は製品群・シリーズ別に分かれている。EHPとGHP、R32とR410A、シリーズ世代を特定した資料を採用すること。
   - 今回の調査だけでは、対象のPanasonic EHP全シリーズに共通する自動増径規則は確定していない。

## 実装前に記録する項目

各ルールについて、次を記録する。

- メーカー、シリーズ、冷媒、運転方式、適用機種・容量範囲
- ルール対象区間（室外機～第一分岐、分岐～分岐、分岐～室内機、BSユニット関連等）
- 判定に使う長さの定義（実長／相当長／最長経路長／特定区間長）
- 境界演算子（`>`、`>=` 等）と増径対象（ガス管／液管／両方）
- 標準管径、増径後管径、異径継手の要否
- 公式資料名、発行日、ページ番号、URL、確認日
- BOMの材料区分・長さ集計・異径継手数量への反映方法

## 検証手順

1. メーカー公式資料で機種と配管区間の適用範囲を確定する。
2. 境界の直前・境界値・直後をテストする（例：89.9m、90.0m、90.1m）。ただし資料の定義に従い、実長と相当長を混ぜない。
3. 分岐系統で、施工総延長と各経路長、対象主管区間長が別々に計算されることを確認する。
4. 増径の結果が配管計算・表示・BOMで一致することを確認する。
5. 未対応機種、欠落データ、資料の版不一致では自動増径せず、要確認として表示する。
6. 既存ケースの前後比較と回帰テストを実行し、結果と根拠資料を監査記録に残す。

## 現時点の実装方針

`shared/ghp-piping-segments.js` は配管区間の構造抽出専用とし、メーカー固有のサイズアップ判定を持たせない。メーカー別ルールは公式資料の対象区間・長さ定義・管種が確定し、既存UI・計算エンジン・BOMまで一貫したテストが準備できてから追加する。
