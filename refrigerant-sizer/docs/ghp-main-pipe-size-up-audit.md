# GHP 主管サイズアップ処理の監査メモ

更新日: 2026-10-20

## 結論

GHP 4アプリの現行サイズアップ処理は、現時点では設計計算として信頼できる状態とは判断できないため、安易なコード修正は行わない。メーカー・シリーズ別の公式条件を確定し、配管ツリーの「ノードが表す配管区間」を整理したうえで修正する。

## コード上で確認した問題

対象:
- `daikin-ghp-refrigerant-sizer/js/engine.js`
- `yanmar-ghp-refrigerant-sizer/js/engine.js`
- `aisin-ghp-refrigerant-sizer/js/engine.js`
- `panasonic-ghp-refrigerant-sizer/js/engine.js`

4アプリ共通で、概ね次の構造になっている。

1. `findLongestPath(tree)` の値が 90 m を超える、または手動指定された場合に `forceSizeUp` を有効にする。
2. 警告文では「最遠相当長が90mを超過」と説明しているが、コード上の経路長計算はツリーの `length` を合算しており、継手相当長を加算していることは確認できない。したがって、現状の `longestPath` を相当長として扱う根拠が不足している。
3. サイズアップ処理は `node.type === 'outdoor'` の場合にだけ実行される。
4. 再帰処理では子ノードへ `false` を渡す。
5. `aggregateBOM` は outdoor ノードの配管長を集計対象外としている。UIの初期ツリーでも室外機ノードの `length` は 0、配管長を持つのは子ノードである。

このため、サイズアップされた値が室外機ノードにだけ設定され、実際の配管長を持つ下流ノードのBOMへ反映されない可能性が高い。2管式・3管式の両方で確認が必要。

## 公式資料から確認できた条件（対象シリーズ・資料の適用範囲に注意）

- **アイシン（R410A資料）**: 公式総合カタログの施工情報では、配管相当長が100m以上の場合、主配管の液管・ガス管を1サイズアップと記載。現行コードの一律90m判定とは一致しない。
  - https://www.aisin.com/jp/product/energy/ghp/pdf/301_all.pdf
- **パナソニック（R410A資料）**: 公式資料では、最大配管長 L1 が90m（相当長）を超える場合、または室内ユニット合計容量が室外ユニットに対して130%を超える場合、主配管（LA）の液管・ガス管を1ランクアップと記載。現行コードは容量比率条件をサイズアップ判定に含めていない。
  - https://hvac.panasonic.com/search/add-on/hvac/fileDownload2.jsp?hinban=U-GZ710S1DRE&itemID=t000100059456&volumeName=00001
- **ヤンマー**: 公式カタログの検索可能テキストでは、相当長90m以上のロング配管時にガス管を1サイズアップして能力低下を抑える説明を確認。ただし、対象機種・配管区間・液管も対象かは、該当シリーズの設計資料で再確認が必要。
  - https://www.yanmar.com/media/jp/2020/ebook/ghp-dh_202011/HTML/index276.html
- **ダイキン（冷暖フリー・GHPエグゼアIIの資料）**: 公式カタログの施工概要では、ロング配管時（相当長90m以上）にガス管サイズを1サイズアップできる旨を記載。少なくともこの資料の条件は「液管・ガス管を両方サイズアップ」とする現行コードとは一致しない。対象シリーズ・管系統・適用条件を限定して扱う必要がある。
  - https://ec.daikinaircon.com/ecatalog/CP21067FXX/images/CP21067FXX221.pdf
- **ダイキン（GHPハイパワープラスの資料）**: 公式カタログには相当長の算定について、実配管長に継手類・分岐部品等の直管相当長を加える考え方と、継手径別の相当長表が掲載されている。相当長判定を実装する場合は、対象シリーズの部品構成に合う表を使う必要がある。
  - https://ec.daikinaircon.com/ecatalog/CP21067AX1/images/CP21067AX1214.pdf

上記資料はメーカー・世代・冷媒・シリーズの適用範囲が異なる可能性があるため、別シリーズへ条件を流用しないこと。特にダイキン資料の「90m以上」は冷暖フリー機の施工概要に関する記載であり、全シリーズ共通ルールとしては扱わない。

## 修正前に必要な設計判断

1. 各アプリの対象シリーズごとに、現行の公式設計資料からサイズアップの閾値、対象管（液管・ガス管等）、対象区間（主配管LA等）、サイズアップ段階を確認する。
2. 配管長入力が実長か相当長かを明確にし、継手相当長を計算していない場合は、相当長と表記しない。
3. 配管ツリーの各ノードが「親からノードまでの区間」を表す現行モデルを前提に、主配管区間を明示できるようにする。室外機ノードの径を変えるだけではBOMへ反映されないため、単純に `forceSizeUp` を子へ伝播させるだけの修正は避ける。
4. 主配管と分岐後の配管が異なる径になり得る位置を表現し、必要なら異径継手・区間分割をBOMに反映する。
5. 公式資料の数値を使った回帰テストを、メーカー・シリーズ別に追加する。

## 現段階の対応

- コードの不整合と公式資料で確認できた差異を記録した。
- 誤った径を確定出力するリスクを避けるため、今回この処理自体は変更していない。
- 次の実装は、シリーズ別の公式条件と配管区間モデルを確定した後に行う。

## 追加調査（2026-10-20）

### 公式資料をコードへ直接当てはめられない理由

今回、メーカー公式資料の該当記述を再確認した。

- **アイシン**の2026年4月版「ハイブリッド空調システム」カタログでは、最適配管相当長が100mを超える場合に主配管を1サイズアップし、連絡キット〜第一分岐のサイズ表でガス管・液管をそれぞれ指定している。また、分岐以降の配管径が主配管径を超えないよう指示している。これは現行アプリの「90m超で室外機ノードだけを一律サイズアップ」という処理とは異なる。なお、これはハイブリッドシステムの資料であり、アイシンの全GHPシリーズに一律適用できる根拠ではない。
- **ヤンマー**の2020年総合カタログの該当ページでは、ロング配管（相当長90m以上）時にガス管を1サイズアップできる旨を確認した。液管も必ず同時にアップするとは読み取れず、またアプリに登録されている各シリーズとの適用対応表は未確認。
- **パナソニック**の公式技術情報には、最大配管長90m相当長以下かつ室内ユニット合計容量が室外ユニットに対して130%を超えない場合に限って使用可能な配管径の条件がある。これは「サイズアップ条件」の単純な閾値というより、配管径表の使用条件として読む必要があり、現行コードの一律90m判定にそのまま置き換えられない。
- **ダイキン**の2025年総合カタログの該当ページは「冷暖フリー（GHPエグゼアII）」向けであり、アプリの全シリーズに適用できる共通ルールではない。現行のシリーズ名・機種名と、資料の対象型式を一つずつ照合する必要がある。

### 実装判断

1. **現時点では、4メーカー共通の自動サイズアップを有効な設計機能として扱わない。** 90mという数字だけを共通条件にすると、閾値・対象管・対象区間・サイズアップの方法を誤る。
2. 実装に先立ち、各シリーズの型式・冷媒・2管式/3管式・主配管の定義を公式資料と照合した対応表を作る。
3. 「相当長」を判定に使うシリーズでは、継手・分岐部材の相当長を加算する入力/計算モデルが必要。現在の `findLongestPath()` はツリーの入力長を足しているだけで、継手相当長を算定している根拠がない。
4. 主配管と分岐後の枝管で径が異なる場合に備え、どのエッジが室外機〜連絡キット〜第一分岐の主配管かをデータモデル上で表現し、異径継手もBOMへ出す必要がある。
5. 公式資料の条件が確定したシリーズから、閾値直前・閾値ちょうど・閾値超過、容量比率条件、2管式/3管式、分岐前後を含む回帰テストを作り、計算結果とBOMの両方を検証する。

### 現在のユーザー向け注意点

配管サイズアップを伴う計算結果は、現状ではメーカー公式基準に基づく確定設計値として使用しないこと。通常の配管径選定を含め、実設計では対象型式の最新施工・設計資料で照合する。コード修正は、誤ったサイズを自動表示する状態をさらに強化しないよう、シリーズ別の適用根拠が取れた段階で実施する。


## 追補: アイシン資料の閾値差異とシリーズ照合（2026-10-20）

アイシン公式資料を再検索した結果、同一メーカーでも対象シリーズ・文書によって**100mの境界条件が異なる**。

| 公式資料 | 記載された条件 | 対象 |
| --- | --- | --- |
| 2026年4月版GHP総合カタログ（R410A）施工情報 | 最遠配管相当長が **100mを超える場合**、主配管を1サイズアップ | 該当資料に掲載の配管系統 |
| Fシリーズ施工概要 | 配管相当長が **100m以上** の場合、主配管の液管・ガス管を1サイズアップ | Fシリーズ |
| ハイブリッド空調システム施工情報 | 最遠配管相当長が **100mを超える場合**、連結キット〜第一分岐の主配管をサイズアップ | ハイブリッド系統 |

出典:
- https://www.aisin.com/jp/product/energy/ghp/pdf/301_all.pdf
- https://www.aisin.com/jp/product/energy/ghp/pdf/021_construction.pdf
- https://www.aisin.com/jp/product/energy/ghp/compunit/hybrid/index.html

**境界値100.0mの挙動は資料の適用シリーズ確定前に実装しないこと。** 単に `>= 100` や `> 100` へ書き換えるだけでは誤選定の可能性がある。

また、アイシン公式のシリーズ別システム例では、Gシリーズ、Fシリーズ、E5シリーズで第一分岐以降の許容長が異なる（G/F: 90m、E5: 60m）。これは主管サイズアップの閾値とは**別の制限値**である。現行アプリのシリーズID（`aisin_ghp_xair`、`aisin_ghp_heat_recovery`、`aisin_ghp_standard`、`aisin_ghp_hybrid`）とメーカーの型式・シリーズ世代との対応が確認できるまで、一律の閾値や制限値を適用しない。

参考: https://www.aisin.com/jp/product/energy/ghp/compunit/setup/

### コード変更の安全策

- 2026-10-20、GHP 4メーカーの `engine.js` の「主管サイズアップを適用しています」という断定的な警告文を、未検証の計算結果を公式資料で照合するよう促す警告へ変更した。
- **計算ロジックは変更していない。** 自動判定と手動サイズアップは引き続き従来ロジックで動くため、注意文の追加だけで設計精度が保証されるわけではない。
- 公式資料と対応づけられるまでは、サイズアップを伴う出力を確定設計値として使わないこと。
