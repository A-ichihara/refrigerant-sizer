# ダイキンGHP 登録型式・冷媒の照合メモ

更新日: 2026-10-20  
対象エンジン: `refrigerant-sizer/daikin-ghp-refrigerant-sizer/js/engine.js`

## 結論

現行エンジンの5シリーズについて、登録型式・冷媒・配管方式と、同一型式に適用されるメーカー公式の設計・施工資料を一対一で結び付ける照合は未完了。型式が見つからないことのみを根拠に、型式が存在しないとは断定しない。公式の適用資料を特定するまで、管径・分岐部材・BOM・許容長の結果を確定設計値として扱わない。

## 公式資料の確認状況

ダイキン公式カタログサイトでは、2025年1月発行の「ガスヒートポンプエアコン総合カタログ」と、2026年6月発行の「ガスヒートポンプエアコン総合カタログR32」が別資料として公開されている。

- 公式カタログ一覧: https://ec.daikinaircon.com/ecatalog/
- 2026年6月発行・R32版: https://ec.daikinaircon.com/ecatalog/DKCB108/index.html
- 公式過去カタログ検索: https://ec.daikinaircon.com/ecatalog/oldcata_index.html
- 旧R410A世代の資料例（2020年8月発行カタログ内のエグゼアIII／II仕様表）: https://ec.daikinaircon.com/ecatalog/CP20095AX2/images/CP20095AX2026.pdf

この確認で、R410Aの旧世代資料とR32版の現行資料を区別すべきことは確認できた。一方、登録された全型式について、同一型式・同一冷媒・同一シリーズの配管設計／施工資料を一対一で特定できていない。検索結果に型式が現れなかったことを、非実在の証明として扱わない。

## 実装上の注意

- 登録型式がR410Aであることだけを根拠に、現行R32カタログの配管表を適用しない。
- 「スーパーコンビ」「標準」「寒冷地」「冷暖同時」「チラー」は別シリーズとして扱い、相当長の閾値、サイズアップ対象管、主管区間、許容長を共通化しない。
- `daikin_ghp_chiller` は通常のビル用マルチと用途・配管条件が異なる可能性があるため、チラー専用資料を確認する前に他シリーズの管径表を流用しない。
- 現行コードには、相当長90m超または手動指定時のサイズアップ処理があるが、現状の処理は室外機ノードに偏り、実配管区間やBOMに反映されない既知不具合がある。閾値の数値だけを修正しても解決しない。
- 公式資料で適用範囲が確定するまでは、サイズアップ処理をメーカー承認済みの選定ロジックとして扱わない。

## 次の照合手順

1. 5シリーズそれぞれの登録型式を、メーカー公式の型式別納入仕様書・設計資料・施工説明書と照合する。
2. 冷媒、世代、2管式／3管式、室外機とBSユニット等の構成を一致させる。
3. 相当長の定義、継手相当長、サイズアップの閾値（以上／超）、対象管、対象区間、容量比率条件を資料の該当ページとともに記録する。
4. 照合できたシリーズからのみ、閾値境界・配管径・配管区間長・BOMのテストを追加する。
5. 専用資料が確認できないシリーズは、未照合のまま記録し、他シリーズのルールを代用しない。
